## Confirmed wins

### Linear-gain fallback is useful as a complementary analysis signal

- Kept `loudnorm` as the primary analysis representation.
- Added a second analysis representation using one constant percentile-based
  gain (`normalize_analysis_level`), so its waveform/dynamics are not altered.
- It is only tried if loudnorm rejects a coarse window for low confidence or
  waveform/envelope disagreement.
- E02 recovered real anchors at reference 120s, 570s and 600s with
  `linear-gain`; logs label these anchors accordingly. This is a signal
  recovery mechanism, not a final-audio filter.

### Dense adaptive scan fixed the tail by listening validation

- Added a 10s-window / 5s-step dense scan only inside gaps larger than 30s.
- Requires a neighbouring dense measurement with a matching offset, avoiding
  isolated correlation peaks.
- User verified this fixed E02's final desync. Keep this strategy.

## E02 10:15 problem: evidence so far

Coarse anchors report:

- Reference 600s: offset -4.607s.
- Reference 630s: offset -6.204s.

The legacy binary localizer creates a 1.596s "missing foreign interval" at
reference 615.000s-616.596s and fills it with silence. User hears this as a
bad cut in the middle of voice; it does not solve sync until approximately
10:50.

Integrated `--transition_report_csv` was added to measure every second using
the complete in-memory arrays (not unsafe short AC3 seeks). Findings:

- 10:04-10:15 consistently supports offset about -4.61s.
- 10:16-10:34 is low-energy / ambiguous. A particularly low reference-energy
  point occurs near 10:33 (about -73 dB).
- 10:35-10:58 consistently supports offset about -6.19s, with waveform clearly
  supporting it across several consecutive seconds.

Conclusion: the offset transition appears real but is not at 10:15. The
correct cut should be chosen in the ambiguous low-energy band between the two
stable states, if and only if the states can be robustly confirmed.

## Experiments that did not activate / are not validated

1. Low-energy transition locator based on raw direct-similarity scores did not
   activate; it fell back to the legacy binary result at 10:15.
2. Replaced that state classifier with the existing waveform/envelope correlation
   engine; still did not activate.
3. Broadened its local state-search radius from a fixed 1s to
   `abs(offset_after - offset_before) + 0.25s`; still did not activate.

Likely reason: state classification cannot explain why it fails because it
returned only booleans. The latest change adds verbose `Transition probe`
logging with waveform/envelope offset/confidence for both before/after
hypotheses at every second of every material transition.
