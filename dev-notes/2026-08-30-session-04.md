# 2026-08-30 - Session 04

## Goal

Validate transition refinements on a known-good episode (S01E01), then explore
whether each foreign track can place a global timing replacement at its own
quietest local splice point without losing sync.

## Validated results

### Transition logic regression

- S01E01 regression output completed successfully with final duration error
  0.003s and looked correct on review.
- The unified transition evidence shifted coarse-boundary cuts to locations
  supported by local before/after runs. In E01, replacements moved from roughly
  75s to 79.950s and from 720s to 721.850s; user judged the result better than
  the preceding version.

### Per-track splice analysis

Added `--splice_safety_report_csv PATH`, analysis-only:

- Extracts each selected foreign track as a normalized analysis copy.
- Reports energy on both sides of each replacement's exact source splice time.
- Reports a local low-energy candidate and nearby sustained quiet interval.
- Does not alter output audio itself.

E01 evidence for replacement `AUDIO_REPLACEMENT_0002` (~01:20):

- Existing source boundary: 75.696s, content present (-22.7/-18.2dB).
- Nearby quiet boundary: 76.696s, -66.3/-66.0dB.
- A long quiet interval was not required for an insertion: adding silence at a
  short natural pause preserves all existing dialogue; it only lengthens that
  pause.

### Per-track primary splice placement

Implemented and listening-validated on `E01_per_track_splice.mkv`:

- A replacement can move only inside a containing verified reference silence.
- It moves to the centre of a quiet interval in the primary foreign track.
- The replacement duration and global timeline shift are preserved.
- The modified anchor sequence must remain monotonic; otherwise the move is
  discarded.
- E01's ~01:20 boundary moved source 75.696s -> 76.640s and reference
  79.950-81.950s -> 80.934-82.934s. Final duration remained within 0.003s.
- User listened and reported it sounds natural and perfect.

This behavior is now ON by default for the primary foreign track. It can be
opted out with `--no_per_track_splice_placement`.

## Important scope limits

- Primary-track splice placement is generic, not E01-specific. No episode
  names or timestamps are in the algorithm.
- It does not yet set independently optimized splice points for additional
  foreign tracks. Those tracks still use the global recipe and need a separate
  design before enabling the same behavior there.
- Analysis normalization (`loudnorm`) is used only for choosing safe points;
  output audio remains extracted from pristine working audio.

## Next steps

1. Add per-track boundary placement for additional tracks, preserving each
   track's common global duration/shift but finding its own safe local edge.
2. Implement per-episode calibration for silence thresholds as a separate
   task, using clean anchors rather than the current fixed -40dB threshold.
3. Only after those are stable, resume eyecatch/bumper and visual-sync work.
