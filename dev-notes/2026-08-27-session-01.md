# 2026-08-27 — Session 01

## Goal

Continue work on the AVSync audio-first remaster workflow: fix audio-quality
regressions introduced by earlier loudness normalization, add smarter
gap-filling behavior, then formally document the fork's divergence from
upstream and refresh `README.md`.

## Changes made

### 1. Smart silence-vs-copy decision for reference-audio gap fills
- **Why:** filling a foreign-audio gap (e.g. HQ reference has a song intro the
  LQ recording lacks) by always copying reference audio produced an audible
  hard cut mid-note/mid-phrase when it spliced back into real foreign content.
- Added `audio_alignment.is_safe_splice_point()`: checks local RMS level at
  the cut point; only copies reference audio if it lands on a natural pause,
  otherwise fills with silence of the same duration.
- Wired into all 3 `AUDIO_REPLACEMENT_*` sites in `AVSync_v14.py` (initial
  prefix, initial jump, progressive negative-delta interval).

### 2. Fixed a channel-layout bug in silence generation (regression from #1)
- `anullsrc=cl={DEFAULT_CHANNELS}` with `DEFAULT_CHANNELS=2` is **not** "2
  channels" — ffmpeg interprets `cl=` as a channel-layout mask, and `cl=2` is
  mono ("FR" channel only). Corrupted everything concatenated after it
  (symptom: whole track sounds stretched/slowed with a deep voice).
- Fixed both silence-generation sites to use `cl=stereo`/`cl=mono` instead of
  the raw channel count.

### 3. Decoupled loudness normalization from actual output audio
- **Why:** `loudnorm` was applied to the *same* 48kHz/stereo extraction used
  to cut the final output segments — i.e. it permanently altered the
  dynamics/volume of the delivered audio, not just the internal analysis.
- Split Stage-2 extraction into a pristine PCM copy (`*_full.wav`, used to cut
  real output segments) and a separate normalized analysis copy
  (`*_analysis.wav`, used only for `find_audio_start_end` boundary detection).

### 4. Auto-matching output codec/bitrate to the source
- **Why:** muxing always forced AAC 192k regardless of the foreign source's
  real codec/bitrate — unnecessary lossy re-encoding, format not respected.
- `--mux_foreign_codec` / `--mux_foreign_bitrate` now default to `"auto"`:
  detect the source's codec/bitrate via ffprobe and match it
  (`resolve_output_audio_settings()`), falling back to lossless FLAC if the
  source codec has no available encoder.
- Added `--audio_filters` (opt-in only, no default) for optional enhancement
  filters (e.g. `loudnorm`, `highpass`) applied at final encode.

### 5. Level-matching gain for reference-audio splices
- **Why:** even with matching codec/format, the reference and foreign sources
  can have very different overall levels, so a copied reference-audio fill
  could still sound abruptly louder/quieter than its surroundings.
- Added `measure_mean_volume_db()` (ffmpeg `volumedetect`); when a gap is
  filled with reference audio, compares its level to the immediately
  surrounding foreign audio and applies a single clamped (±15dB) linear gain
  — not dynamic-range compression, so the clip's own dynamics are untouched.

### 6. Fork vs. upstream diff analysis + README overhaul
- Diffed the working tree against `upstream/main` (same commit as
  `origin/main`) to catalogue every change: the new audio-anchor-pairing
  subsystem (`audio_alignment.py`, consensus recovery, precise transition
  localization, editorial silence recipe shared with subtitles), resilience
  fixes (segment-level fallback instead of aborting), and bugfixes
  (`avg_frame_rate` for VFR, robust `pts_time` parsing, letterboxed frame
  resize for visual matching, the channel-layout bug from #2).
- Rewrote `README.md`: clarified `v14` = last upstream release before this
  fork diverged; added a formal "Primary Use Case" section (transcribed from
  `OBJETIVO.txt` into standard README prose); added "Audio Quality
  Preservation" section; added a "Quick Test" section with runnable examples
  for the new flags, including explicit recode + `--audio_filters` usage;
  updated the Key Options table (`auto` codec/bitrate defaults,
  `--anchor_source`, `--foreign_anchor_stream_idx`, `--audio_filters`).

## Decisions / tradeoffs

- Kept this as an independent fork rather than opening a single upstream PR:
  the diff is broad (new module, new default workflow, several default
  behavior changes) and reflects a different design intent (audio-first
  remastering) than upstream's visual-matching-first tool. The self-contained
  bugfixes (channel-layout, `pts_time` parsing, VFR frame-rate detection)
  were flagged in the README as reasonable candidates to upstream separately
  later, but that hasn't been done yet.
- Level-matching uses a single linear gain (`volume=XdB`), explicitly *not*
  `loudnorm`/dynamic-range compression, per explicit user request to keep
  corrections surgical rather than global.
